# Walkthrough - Full Pipeline Integration

We implemented the main orchestrator (`src/pipeline.py`) that brings together the motion detection, event segmentation, zone-cropped snapshot generation, and YOLOv8 object detection components. We also verified it using an end-to-end integration test (`tests/test_full_pipeline.py`).

## Changes Made

### Pipeline Orchestrator
#### [NEW] [pipeline.py](file:///d:/ExamVision_Ai/src/pipeline.py)
- Created the `ExamVisionPipeline` class to manage configurations and process video files.
- Integrated the offline motion pipeline to detect and segment candidate events first.
- For each event, generated zone-cropped snapshots and full-frame copies.
- Implemented **two-tier efficiency**: YOLO detection is only run on the peak frame (`after_frame_idx`) of flagged events.
- Added **YOLO inference caching**: Cached detections using `after_frame_idx` as the key. If co-occurring events share the same peak frame, YOLO is executed only once, avoiding redundant computation.
- Implemented **evidence annotations**: If YOLO detects cheating objects, drawn red bounding boxes and confidence labels on the full-frame version and saved as `event_{id}_annotated.jpg`.
- Compiled results into a structured JSON list and saved to `/data/results/{video_name}_results.json`.

### Integration Test
#### [NEW] [test_full_pipeline.py](file:///d:/ExamVision_Ai/tests/test_full_pipeline.py)
- Created the test script to resolve the most recent recording, execute the pipeline, and print efficiency and detection stats.
