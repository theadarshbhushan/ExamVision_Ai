# Walkthrough: Snapshot Generation Feature

We have successfully implemented and verified the "before/after" snapshot generation module (stated differentiating feature) which provides comparative audit trails for cheating incidents.

## Key Changes

1. **Snapshot Module**:
   - Created [src/snapshot/snapshot_generator.py](file:///d:/ExamVision_Ai/src/snapshot/snapshot_generator.py) to manage frame seeking and file storage.
   - Converts timestamps to deterministic frame indices using `frame_idx = int(round(seconds * fps))`.
   - Extracts a baseline baseline (`before`) frame at `max(0.0, start_time - before_offset)` seconds.
   - Extracts a peak-activity (`after`) frame by scanning the motion intensity profile in `motion_results` and choosing the exact timestamp where the target zone's intensity was maximized. Midpoint is used as a fallback if no results are passed.
   - Saves frame images under `data/snapshots/{video_name}/` using the naming structure:
     - `event_{event_id}_before.jpg`
     - `event_{event_id}_after.jpg`
   - Returns a structured dictionary metadata format: `{"event_id", "before_path", "after_path", "timestamp", "zone_id"}`.

2. **Integration Test Utility**:
   - Created [tests/test_snapshot_manual.py](file:///d:/ExamVision_Ai/tests/test_snapshot_manual.py) to run the full motion detector and event segmenter pipeline on the latest webcam recording, triggering snapshot generation for each event.
